# Lab 14

## Co zostało zrealizowane
Zaimplementowano finałowego bossa opisanego maszyną stanów (FSM) z dwiema fazami i zmiennymi hitboxami. Skonfigurowano poprawne warstwy kolizji oraz zintegrowano śmierć bossa z globalnym ekranem końcowym. Przeprowadzono refaktoryzację kodu, zastępując "magiczne liczby" stałymi.

## Uruchomienie
Projekt należy otworzyć w środowisku Godot Engine 4.x.
